What this assessment covers

The 12 prompts, grouped by area. Each one has a "what to look for" note and a concrete action inside the assessment.

Data
  • Is sensitive data minimized on the device?
  • Are secrets excluded from the application package and logs?
  • Are local data protections matched to realistic device threats?
Platform
  • Are exported components and deep links intentionally exposed?
  • Are platform permissions limited to the feature need?
  • Does the application fail safely when platform trust changes?
API
  • Does the server enforce object and function permission for every mobile role?
  • Can tokens and sessions be revoked after logout or device loss?
  • Are transport and certificate decisions deployable without unsafe bypasses?
Release
  • Are debug features and test endpoints excluded from release builds?
  • Can a vulnerable mobile version be contained or retired?
  • Are privacy and security claims consistent with actual behavior?
How scoring works. Only rated prompts count toward the index. Not sure and unanswered prompts are reported separately and never scored as a pass or a gap. Gaps are listed highest priority first, each with a link to a matching template in the open GRC Documentation Kit. This is a conversation starter, not an audit or a certification.
