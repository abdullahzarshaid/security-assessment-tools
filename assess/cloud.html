Scope. 12 vendor-neutral screening prompts, informed by cloud security principles. No account connection, live scan or cloud certification. Reference: AWS Well-Architected security pillar (context only, not an endorsement).

What this assessment covers

The 12 prompts, grouped by area. Each one has a "what to look for" note and a concrete action inside the assessment.

Identity
  • Are privileged identities protected with strong authentication?
  • Are workload permissions limited to their actual purpose?
  • Are long-lived secrets managed and rotated?
Exposure
  • Is internet-facing exposure intentionally approved?
  • Are trust boundaries represented in the architecture?
  • Are risky configuration changes detected or reviewed?
Visibility
  • Are administrative events retained in a protected location?
  • Can alerts be tied back to an accountable service owner?
  • Have logging gaps been exercised safely?
Resilience
  • Can important data be recovered after account compromise?
  • Are infrastructure changes reproducible and reversible?
  • Are cloud responsibilities assigned between providers and your team?
How scoring works. Only rated prompts count toward the index. Not sure and unanswered prompts are reported separately and never scored as a pass or a gap. Gaps are listed highest priority first, each with a link to a matching template in the open GRC Documentation Kit. This is a conversation starter, not an audit or a certification.
